# TG WebGPT Gateway — specification pack

This folder contains the bootstrap specification for a standalone Telegram gateway to browser-based ChatGPT via `codex-chatgpt-web` or a compatible provider adapter.

Read order:

1. `PRODUCT.md`
2. `ARCHITECTURE.md`
3. `ACCEPTANCE.md`
4. `ROADMAP.md`
5. `AGENTS.md`
6. `GOAL.md`

The package intentionally contains specification only, not implementation code.
